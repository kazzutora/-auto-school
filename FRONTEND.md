## A.1 Направление

Минимализм на высоком контрасте. Работает так: почти всё чёрно-белое, ровно один жёлтый акцент, вся выразительность держится на типографике и воздухе, а не на цвете, тенях и градиентах.

Основание — дорожный знак. Чёрное на жёлтом, толстая типографика, ноль декора. Это язык, в котором клиент автошколы живёт каждый день, и он же даёт естественный высокий контраст.

**Правила направления:**

- фон страницы белый, текст почти-чёрный, акцент жёлтый. Третьего цвета нет;
- глубокий фиолетовый из существующего баннера школы остаётся только как ground для инвертированных блоков и футера. Как заливка кнопок и плашек не используется. **С ядра v10** он же — второй тёмный грунт для внутренних страниц: у каждой одна инвертированная полоса, чёрная или фиолетовая. Фиолетовая никогда не стоит последней перед футером — тот тоже фиолетовый, и две полосы слились бы в одну;
- границы вместо теней. Тень допускается ровно одна, на приподнятой карточке при `:hover`, и та едва заметная;
- радиусы: 0 для секций и плашек, 2px для кнопок, полей и карточек. Скруглённых пузырей нет;
- ни одного градиента, ни одного стокового фото людей с ключами от машины;
- иллюстративная нагрузка — только реальные фото школы из галереи и крупная типографика.

**Чего не делать** (это то, во что съезжает почти любая сессия):

- тёплый кремовый фон с serif-заголовком и терракотовым акцентом;
- градиент из фиолетового в синий в шапке;
- `rounded-2xl` + `shadow-lg` на каждой карточке;
- эмодзи вместо иконок;
- центрирование всего подряд;
- три одинаковые «фичи» с иконкой-кружком.

## A.2 Палитра

Определяется токенами в `tailwind.config.js`. Все цвета берутся только через токен, литералов в шаблонах нет.

```js
// Светлая тема — база
paper:   { DEFAULT: "#FFFFFF", 50: "#FAFAFA", 100: "#F2F2F1", 200: "#E6E6E4" }
ink:     { DEFAULT: "#0E0E10", 700: "#33333A", 500: "#5C5C66", 300: "#8A8A94" }
line:    { DEFAULT: "#1A1A1E", soft: "#D9D9D6" }   // line.DEFAULT — жирная рамка, line.soft — разделитель
accent:  { DEFAULT: "#FFD400", 600: "#E5BE00", 100: "#FFF6CC" }
deep:    { DEFAULT: "#2A2060", 700: "#3B2D71" }    // только инвертированные блоки и футер
state:   { ok: "#0F6B45", warn: "#8A5A00", err: "#A62015" }
```

**Тема одна — светлая. Отменено решением владельца, ядро v6.**

Раньше здесь стояла тёмная тема как перестановка ролей на `prefers-color-scheme`.
На практике она давала следующее: `paper` становился почти чёрным, шапка
`bg-paper` совпадала с телом страницы до последнего байта, а разделитель между
ними (`line.soft`) давал контраст 1.4:1. На каждой странице, кроме главной,
шапка попросту растворялась в странице. На главной этого не было видно только
потому, что под шапкой стоит инвертированный герой — он в тёмной теме
становился почти белым и создавал границу.

Вместо темы — **тёмная полоса шапки над светлой страницей, всегда**. Шапка
публикует `--ground: ink`, её содержимое читает `--on-ground`, поэтому ни один
компонент внутри не называет цвет.

Механизм перестановки ролей остался и работает: `--ground` / `--on-ground` — это
то, чем живут шапка, инвертированный герой и жёлтая полоса. Ушёл только второй
набор значений токенов.

**Контраст обязателен и проверяется:**

- текст на фоне — минимум 4.5:1, крупный текст и заголовки — минимум 3:1;
- чёрный на жёлтом `#0E0E10` / `#FFD400` = 13.6:1, это основная пара для кнопки-CTA;
- **белый текст на жёлтом запрещён** — контраст 1.6:1. На жёлтом только почти-чёрный;
- фокус — жёлтая обводка 2px с отступом 2px, на жёлтом фоне переключается на почти-чёрную.

**Роль акцента.** Жёлтый — это «сделай действие». Он появляется на: главной кнопке, sticky-панели звонка, полосе про занятия на русском и украинском, маркере активного пункта навигации, подчёркивании одного слова в `h1`. Больше нигде. Если жёлтого на экране больше трёх пятен — он перестал работать.

## A.3 Типографика

Три семейства, все самохостом в `static/fonts/`, формат woff2, `font-display: swap`. Внешних хостов нет.

| Роль | Шрифт | Начертания | Где |
|---|---|---|---|
| Дисплей | **Archivo** (в т.ч. Expanded) | 700, 800 | h1, h2, крупные числа, коды категорий |
| Текст | **Public Sans** | 400, 600 | абзацы, списки, поля, кнопки |
| Утилита | **Roboto Mono** | 400, 500 | цены, телефоны, даты, часы, коды, лейблы |

Моноширинный несёт данные: цену, дату старта, телефон, часы работы, код категории. Это делает данные читаемыми в колонку и визуально отделяет «факт» от «текста». Везде, где цифры выстраиваются в столбец, добавляется `font-variant-numeric: tabular-nums`.

**Шкала** (`clamp` от мобильного к десктопу):

```
display   clamp(2.75rem, 7vw, 5.5rem)   / 0.95 / -0.02em / Archivo Expanded 800 / uppercase
h1        clamp(2.25rem, 5vw, 3.75rem)  / 1.02 / -0.02em / Archivo 800
h2        clamp(1.75rem, 3.2vw, 2.5rem) / 1.08 / -0.01em / Archivo 700
h3        1.25rem                       / 1.25 / 0       / Archivo 700
body-lg   1.125rem                      / 1.6            / Public Sans 400
body      1rem                          / 1.65           / Public Sans 400
small     0.875rem                      / 1.5            / Public Sans 400
label     0.75rem                       / 1.2  / 0.12em  / Roboto Mono 500 / uppercase
data      1rem–2rem                     / 1.1  / -0.01em / Roboto Mono 500 / tabular-nums
```

Правила:

- ровно один `h1` на странице, порядок заголовков не перескакивает через уровень;
- строка текста 60–75 символов, шире не растягивать;
- `text-wrap: balance` на всех заголовках, `text-wrap: pretty` на лидах;
- uppercase только на `label` и `display`, в абзацах никогда;
- переносы в польском: `hyphens: auto` с `lang="pl"`, иначе длинные слова рвут сетку на 320px.

## A.4 Сетка, ритм, точки перелома

```
Контейнер:   max-width 1200px, padding 20px (мобильный) / 32px (≥768) / 48px (≥1280)
Узкий текст: max-width 68ch внутри контейнера
Шаг ритма:   4px. Разрешённые значения: 4 8 12 16 24 32 48 64 96 128
Секция:      py 64px (мобильный) / 96px (≥768) / 128px (≥1280)
Брейкпоинты: sm 480, md 768, lg 1024, xl 1280
```

Отступы делает layout: `flex`/`grid` + `gap`. Персональные `margin` на элементах не используются, кроме `margin-bottom` внутри текстовых блоков.

Любой широкий блок — таблица, код, ряд карточек — скроллится внутри своего контейнера с `overflow-x: auto`. Страница вбок не едет ни на одной ширине от 320px.

## A.5 Компоненты: состояния и детали

Список компонентов заморожен в `tech.md` §7. Здесь фиксируются их визуальные состояния.

**Кнопка.** Высота 48px (`md`), 56px (`lg`), 40px (`sm`). Радиус 2px. Горизонтальный padding 24px.

| Вариант | Покой | Hover | Active | Focus | Disabled |
|---|---|---|---|---|---|
| `primary` | жёлтый фон, почти-чёрный текст | фон `accent.600` | сдвиг вниз 1px | обводка ink 2px, offset 2px | `paper.200` фон, `ink.300` текст, `cursor: not-allowed` |
| `secondary` | прозрачный фон, рамка ink 2px | фон ink, текст paper | сдвиг вниз 1px | обводка accent | рамка `line.soft`, текст `ink.300` |
| `ghost` | только текст + подчёркивание при hover | подчёркивание | — | обводка accent | текст `ink.300` |

Кнопка всегда говорит, что произойдёт: `Zapisz się`, `Zadzwoń`, `Zobacz terminy`. Не `Kliknij tutaj`, не `Więcej`.

**Поле формы.** Высота 48px, рамка `line.soft` 1px, при `:focus` — рамка ink 2px без смещения layout (используем `box-shadow: inset 0 0 0 1px`, не толщину границы). Ошибка: рамка `state.err`, под полем текст ошибки 14px, связан через `aria-describedby`. Лейбл всегда видим, `placeholder` не заменяет лейбл.

**Карточка.** Фон paper, рамка `line.soft` 1px, радиус 2px, padding 24px. При `:hover` на кликабельной карточке — рамка становится ink 1px и появляется тень `0 2px 0 0 var(--ink)` (жёсткая, без размытия, в духе направления). Вся карточка кликабельна, но фокус ловит внутренняя ссылка-заголовок.

**Бейдж.** Высота 24px, `label`-типографика, рамка 1px. `neutral` — рамка `line.soft`; `success` — рамка и текст `state.ok`; `warning` — `state.warn`; `danger` — `state.err`. Заливка только у одного варианта: `accent` — жёлтая заливка, почти-чёрный текст, для «Nowy termin».

**Таблица.** Заголовок — `label`-типографика, нижняя граница ink 2px. Строки разделены `line.soft`. Числовые колонки — `data`-типографика, выравнивание вправо, `tabular-nums`. Зебры нет.

**Аккордеон.** Нативные `<details>/<summary>` как основа, Alpine только для плавности. Индикатор — плюс/минус, не шеврон. Работает без JS.

**Модалка.** Ground `ink` с прозрачностью 0.6, панель paper, рамка ink 2px, ширина до 560px. Фокус запирается внутри, `Esc` закрывает, при закрытии фокус возвращается на элемент, который её открыл.

**Sticky CTA.** Только ниже `md`. Фиксирована снизу, высота 64px, фон paper, верхняя граница ink 2px, две кнопки в ряд: `Zadzwoń` (primary) и `Zapisz się` (secondary). Учитывает `env(safe-area-inset-bottom)`. Не перекрывает cookie-баннер: баннер всегда выше.

## A.6 Движение

По умолчанию движения нет. Разрешены три вещи:

1. `transition: 120ms ease-out` на цвет, границу и фон интерактивных элементов;
2. раскрытие аккордеона и мобильного меню, 180ms. Ни то, ни другое не работало до v9: нативный `<details>` не рендерит содержимое, пока закрыт, поэтому высоте не от чего ехать, а `<dialog>` через `showModal()` появляется за один кадр. Оба доведены скриптом и ключевыми кадрами; без javascript обе вещи по-прежнему открываются, просто сразу;
3. появление секции при скролле — только `opacity` от 0 до 1 за 300ms, один раз, без смещения. Без параллакса, без вылета сбоку.
4. **(ядро v7, расширен в v8 — решение владельца)** отклик на наведение. `transform` разрешён только для перечисленного:

| что | движение |
|---|---|
| карточка-ссылка, ценовая плитка | подъём на 4px |
| иконка в кнопке | рост до 1.08 |
| стрелка `arrow-right` в кнопке | сдвиг вправо на 3px |
| иконка `external` в кнопке | сдвиг на 2px вправо и вверх |
| индикатор аккордеона | рост до 1.15 |
| фотография в плитке галереи и скан сертификата | рост до 1.04 внутри обрезанной рамки, 300ms |
| строка расписания | фон `paper-50` (пункт 1, `transform` не нужен) |
| плитка категории | подъём на 4px, буква категории ведёт — на 2px раньше |
| пункт меню | жёлтое подчёркивание выезжает слева, `scaleX` 0→1 |
| строка мобильной панели | сдвиг вправо на 4px |

Пункт 4 добавлен по прямой просьбе владельца после того, как сайт стал казаться неподвижным, и расширен, когда одного подъёма оказалось мало. A.1 уже говорил о «приподнятой карточке при :hover» и дал ей единственную разрешённую тень — не хватало только права доехать до этого положения, а не прыгнуть.

Величины намеренно разные. Стрелка едет, а не растёт: кнопка, означающая «дальше», должна показывать направление, и на сайте, чей язык — дорожный знак, это читается лучше раздувания на месте. Иконка в кнопке — 1.08, а не больше: она стоит на базовой линии рядом со словом. Фотография — 1.04 и медленнее, потому что двигается большая площадь.

Ценовая плитка, строка расписания и индикатор аккордеона до v8 не отвечали на указатель вовсе. Плитка категории и строки мобильной панели — до v9.

Подчёркивание пункта меню — единственное исключение из сброса под `prefers-reduced-motion`: это состояние, а не украшение, поэтому оно продолжает появляться, только мгновенно. Сброс `transform` подчеркнул бы разом все пункты. Маркер текущей страницы держится на `aria-current="page"` — том же атрибуте, что читает скринридер, так что вид и озвучка не разойдутся.

Всё это выключается целиком внутри `@media (prefers-reduced-motion: reduce)`. Для пункта 4 обнуления длительности мало — оно оставляет прыжок вместо перехода, поэтому `transform` там сбрасывается явно. Граница и тень при этом продолжают отвечать на указатель, так что карточка не немеет.

## A.7 Иконки

Локальный SVG-спрайт `static/icons/sprite.svg`. Сетка 24px, обводка 1.75px, `currentColor`, скруглённые концы. Нужный минимум: телефон, конверт, карта-пин, часы, календарь, стрелка-вправо, крестик, плюс, минус, чек, меню, глобус, скачать, внешняя ссылка.

Иконка никогда не стоит одна вместо текста, кроме кнопки закрытия и бургера — у них `aria-label`. Эмодзи в интерфейсе нет.
