# CLAUDE.md

Проект: сайт автошколы OSK Ostrycharz, Wieluń. Django 5.1 + PostgreSQL 16 + Celery/Redis + Django Templates (django-cotton) + HTMX + Tailwind.

## Комплект

Файлы в корне репозитория:

- **`tech.md`** — источник истины. Схема БД, контракты Celery-задач, URL-карта, UI-компоненты, контракт `Seo`, доктрина тестов, инфраструктура, конвенция коммитов.
- **`DEV.md`** — часть I: порядок сборки скелета и чек-листы (режим LEAD). Часть II: стадийный список задач (режим DEV).
- **`PROMPTS.md`** — промпты бэкенда: по одному на каждый шаг скелета и каждый слайс.
- **`ROSE.md`** — визуальный язык по логотипу владельца. **Часть B устарела с ядра v43** — палитра стала фирменной красно-бело-синей, её источник теперь блок токенов в `static/src/css/app.css`, а меряет `scripts/check_contrast.py`. Действуют часть A (разбор макета), B.4–B.5 (шрифты, шкала, радиусы, состояния), B.6–B.7 (орнамент и норма расхода), часть C (композиция), часть D (промпты K0–K8), часть E (чек-лист).
- **`REDESIGN.md`** — **часть B устарела с ядра v29**, её значения не применять. Действуют часть C (анимация) и часть D (фотографии).
- **`FRONTEND.md`** — промпты фронтенда F0–F11 (часть B). **Часть A устарела с ядра v25**, её токены не применять.
- **`PHOTOS.md`** — фотографии: источники, лицензии, обработка, водяные знаки.
- **`FRONTEND_FIXES.md`** — аудит работающего сайта: 18 находок с адресами, промпты X0–X8.
- **`BLOCKS.md`** — каталог 18 блоков и готовый набор по каждой странице.
- **`OSTRYCHARZ.md`** — данные этого клиента, дословно с их сайта, разбор отличий и промпты O0–O8, по которым собран этот форк.
- **`CLAUDE.md`** — этот указатель.

Прочитай `tech.md` перед любой работой и подчиняйся ему дословно. Зафиксируй в начале сессии версию ядра из его шапки. Версия сменилась — перечитай changelog до того, как писать код.

## Режим сессии

Один человек, два режима, **не смешивать в одной сессии**:

- скелет, контракты, миграции, общие файлы, CI/CD, ревью → `DEV.md`, часть I;
- фича → `DEV.md`, часть II, ровно **одна** задача из стадийного списка.

Контракты меняются только в режиме LEAD, с бампом версии `tech.md`.

## Жёсткие правила

1. **Контракты не выдумывай.** Нет нужного поля, типа, задачи, эндпоинта или пропса компонента — СТОП. Выдай блок `CONTRACT GAP` (форма в шапке `DEV.md` и в `tech.md` §11), открой issue `contract-change`, продолжай на локальной заглушке.
2. **Миграции пишутся только в режиме LEAD.** В режиме DEV не запускай `makemigrations` и не коммить файлы миграций.
3. **Не трогай общие файлы** в режиме DEV: `config/`, `apps/core/`, `templates/cotton/`, `templates/base.html`, `templates/layout/`, `tailwind.config.js`, `scripts/seed.py`, `.github/`, `deploy/`.
4. **UI только через cotton-компоненты** из `templates/cotton/`. Свою разметку кнопок, полей и карточек не пиши.
5. **Тесты выводятся из критериев приёмки, не из реализации.** Каждая Celery-задача обязана иметь тест идемпотентности. На стыке слайса обязателен контрактный тест.
6. **Эталон** — слайс `apps/gallery`. Повторяй его структуру.
6a. **Фронтенд-сессия питон не трогает.** Только `templates/`, `static/`, `tailwind.config.js`. Не хватает данных в контексте шаблона — `CONTRACT GAP`, а не правка вьюхи. **Цвет — только из токенов `static/src/css/app.css`; `ROSE.md` часть B, `REDESIGN.md` часть B и `FRONTEND.md` часть A не применять.** Шкала и радиусы — `ROSE.md` B.4–B.5, норма орнамента — B.7. Свою палитру не изобретай. Три цвета и никакого четвёртого: красный, белый, графит. Красный `brand.500` — действие, крупные заголовки, кольцо фокуса; мелкий красный текст только `brand.600` и темнее (`brand.500` на грунте даёт 4.42). Графит `brand.700` — текст, заголовки, вторичная кнопка, тёмная полоса, подвал; на графите красный только крупно и небуквами. Логотипный `#EA232C` в таблицу стилей не попадает — гейт контраста роняет сборку.
6b. **Ничего не выдумывай про школу.** Каждый факт на сайте — из `OSTRYCHARZ.md` часть A дословно. Нет цифры — `TODO_OWNER` и строка в `owner_data_gaps()`, а не правдоподобная замена. Отзывы и рейтинг в разметке — только с `source_url`.
6c. **Библиотеку анимации не подключать** — ни GSAP, ни Motion, ни AOS. Движение делают CSS scroll-driven animations, CSS-переходы и уже подключённый Alpine, `REDESIGN.md` C.2.
6d. **Данные из макета не переносить.** `static/img/brand/source/mockup-home.png` сгенерирован нейросетью: 98% сдачи, 10+ lat, 1000+ kursantów, категории A/A1/C/D, отзывы со стоковыми лицами, Instagram и TikTok — всё это выдумано. Из макета берётся только внешний вид, разбор в `ROSE.md` A.3.
7. **Внешние сервисы только через клиенты** `apps/core/clients`. В dev и тестах всегда фейки.
8. **Никаких внешних CDN** на публичных страницах: скрипты, шрифты, тайлы аналитики. Всё самохостим.
9. **Одна задача за сессию**, сфокусированный дифф, маленькие коммиты по ходу.

## Коммиты

Английский. `type(scope): summary`, `type` из `feat|fix|test|refactor|chore|docs`, императив, строчная, без точки, до ~50 символов. Коммить по ходу работы, не одним куском в конце.

## Команды

```
make up        # docker compose up
make migrate   # применить миграции
make seed      # наполнить базу фикстурами
make test      # pytest + покрытие
make lint      # ruff + mypy
make css       # сборка Tailwind
make e2e       # Playwright
```
