# Фирменный знак

Собран по логотипу владельца, `ROSE.md` K1. Исходники — в `source/`, наружу не
отдаются. Всё в этой папке **генерируется**, руками не правится:

```
python -m scripts.brand.fetch_fonts        шрифты в static/fonts/ (нужен интернет)
python -m scripts.brand.gen_logo           svg: логотипы, метки, фавикон
python -m scripts.brand.gen_lockup_raster  знак страниц из авторского файла
python -m scripts.brand.gen_icons          png/jpg: иконки и og-карточка
python -m scripts.brand.sheet              контактный лист в .local/
```

Генераторам нужен `fontTools` — он объявлен в группе `dev` в `pyproject.toml`.
Если контейнер его не видит, образ старше этой строки: `docker compose build web`.

Геометрия — `scripts/brand/geometry.py`, одна на оба рендерера: svg рисует
`gen_logo.py`, png рисует Pillow в `gen_icons.py`. Правка знака — правка чисел
там, а не в выходных файлах.

| Файл | Где применяется |
|---|---|
| `logo-full.svg` | письма, пресс-кит — со слоганом |
| `logo-full-dark.svg` | то же на тёмном грунте |
| `logo-compact.svg` | письма и печать, где нужен вектор. На страницах **не используется** с ядра v31 |
| `logo-compact-dark.svg` | то же на тёмном |
| `lockup-owner.avif`, `.webp` | **знак шапки и футера.** Активный авторский файл, порезанный `gen_lockup_raster.py` |
| `lockup-owner-dark.avif`, `.webp` | он же с перекрашенной под тёмный грунт краской |
| `mark-wheel.svg` | руль отдельно |
| `mark-l.svg` | табличка `L` с шапочкой — герой главной, когда фото машины школы нет |
| `favicon.svg` | табличка `L` без шапочки, квадратная |
| `favicon-96.png` | то же растром, прозрачный фон |
| `apple-touch-icon-180.png` | фон `brand.100` |
| `icon-192.png`, `icon-512.png` | PWA |
| `maskable-512.png` | знак в средних 52% — лаунчер обрежет всё за пределами 80% |
| `og-default.jpg` | `og:image` по умолчанию, 1200×630 |

## Почему знак страниц — растр

С ядра v31 шапка и футер показывают авторский файл, а не вычерченный. Владелец
прислал готовую работу: кистевые штрихи с рваным краем, рисованные сердечки,
бумажная текстура. Геометрией это не описывается, и перерисовка — это уже
другой знак, а не тот, о котором просили.

Владелец прислал не один файл. Все они перечислены в `PIECES` внутри
`gen_lockup_raster.py`, а `ACTIVE` говорит, какой стоит на сайте — смена знака
это одно слово, и у неиспользуемых вариантов сохраняются их обмеры.

| Имя | Файл | Что на нём |
|---|---|---|
| `wheel` | `lockup-owner.png` | руль, сердечки, слоган рукописью |
| `crown` | `lockup-owner-v2.png` | корона вместо руля, слова кистью, без слогана |
| `outline` | `lockup-owner-v3.png` | корона, слово контуром, чистая подстрока. **Сейчас активен** |

У `outline` нет прозрачности: он прислан на белой подложке. Её снимает
заливка от края кадра, а не выбивание белого по всему полю — внутри букв есть
белая линия, и выбивание сняло бы её вместе с подложкой, а заливка до неё не
дотягивается: малиновый контур её запирает.

Что делает `gen_lockup_raster.py`:

1. **Стирает слоган**, а не отрезает его — у тех файлов, где он есть. Под
   провалом ниже подстроки у `wheel` лежат четыре разные вещи, и слоган только
   две из них: руль уходит до 0.812 высоты, табличка до 0.763, а слоган
   начинается на 0.725. Горизонтальный рез срезает низ руля и таблички — первая
   попытка ровно это и сделала. У `crown` слогана нет, и шаг пропускается.
   В футере слоган всё равно стоит рядом текстом, выделяемым и в Caveat.
2. **Перекрашивает краску под тёмную тему.** Тёмное на этих файлах — слово
   или подстрока — на тёмной странице чёрное по чёрному. Малиновый не
   трогается: `ROSE.md` B.2, заливки не меняются местами, меняются роли.

   Разделяет их **темнота и оттенок**, а не насыщенность. Насыщенность была
   первым правилом, держалась на двух первых файлах и сломалась на третьем: у
   его подстроки почти чёрный с синим отливом, `(15, 33, 47)`, а насыщенность
   в HSV считается от старшего канала — 47 против 15 даёт 0.68, насыщеннее
   пастели. Подстрока осталась бы чёрной на тёмной теме.
3. **Обрезает поля по порогу**, а не по `getbbox()`: у файлов по всем краям
   дымка из альфы 1–2, и обычный вызов не обрезает ничего.

Отдаётся фоном в CSS (`.u-lockup`), а не через `<img>`. Два `<img>` со скрытым
по теме — это два запроса за одной картинкой, браузер тянет оба; правило CSS,
которое не применилось, свой файл не грузит. Плата — отсутствие `alt`, поэтому
имя школы несёт `aria-label` на ссылке вокруг.

**Малиновый в авторском файле не из палитры.** Там примерно `#DC0040`, в
палитре `brand.500` — `#D4385E`, заметно розовее. Товарный знак имеет право на
свой цвет, но рядом с кнопками разница видна. Если нужно свести — это правка
в `gen_lockup_raster.py`, не в файлах.

## Чем вычерченный знак отличается от присланного

1. **Слово набрано Rubik 800 italic**, а у владельца — узкий кистевой шрифт.
   При той же высоте прописных наше слово шире примерно на пятую часть.
   Это осознанный размен `ROSE.md` B.4: у Rubik есть кириллица, сайт на трёх
   языках, и логотип, который не умеет написать русскую страницу, хуже
   логотипа чуть шире.
2. **Цвета сведены к палитре** `ROSE.md` B.2. Заливки плоские: у присланного
   файла градиенты, тени и текстура бумаги, которые в svg на 40px всё равно
   пропадают.
3. **У углов вырезов в руле есть скругление** в svg и нет в png: растровый
   рендерер рисует секторы примитивами Pillow. Заметно примерно от 300px,
   а самый крупный растр — og-карточка, где руль 145px.
4. **Сердечко одно, а у владельца их четыре.** Четыре на 44px — это строчка
   розовых точек. Одно стоит там же, где у него главное: над словом, `ROSE.md`
   B.7.
5. **Мазков кисти вокруг знака нет.** Они живут отдельной библиотекой
   орнамента и расходуются по норме B.7, а не приклеены к логотипу: знак
   должен читаться и в письме, и на визитке, и в фавиконе.

Сверить рядом с оригиналом: `python -m scripts.brand.sheet`, потом

```
python -m http.server 8899 --bind 127.0.0.1 --directory .local
```

и открыть `http://127.0.0.1:8899/brand-sheet.html`.

## Если владелец пришлёт вектор

Положить в `source/` и пересобрать: `gen_logo.py` возьмёт готовые кривые
вместо перерисовки. Просить стоит SVG, AI, PDF или PNG от 2000px на прозрачном
фоне.
