## Из макета берётся только вид

`mockup-home.png` и `design-system.png` — ориентиры по внешности, не источник фактов.
Переносить из них данные нельзя, разбор в `ROSE.md` A.3. Коротко, чего в макете нет
на самом деле: `98%` сдачи (реально 76%), `10+ lat`, `1000+ kursantów`, категории
A/A1/C/D (школа учит только B), отзывы Kasia W. / Michał P. / Ola S. со стоковыми
лицами, иконки Instagram и TikTok, белая Toyota с логотипом школы.

## Вектор

Логотип растровый. Если владелец пришлёт векторный исходник — SVG, AI, PDF или PNG
от 2000px на прозрачном фоне — положить сюда и пересобрать комплект по `ROSE.md` K1.
До тех пор знак в `static/img/brand/` перерисован вручную по этим растрам.
