# ЧАСТЬ A — МАКЕТ: ЧТО БРАТЬ, ЧТО НЕЛЬЗЯ

## A.1 Исходники

Положить в репозиторий, **не отдавать публично**:

```
static/img/brand/source/logo-light.png      светлая версия логотипа
static/img/brand/source/logo-dark.png       версия на чёрном
static/img/brand/source/mockup-home.png     макет главной — только референс
static/img/brand/source/design-system.png   лист стиля владельца — только референс
```

`source/` исключается из `collectstatic` и из деплоя. Макет — картинка-ориентир, а не ассет: из него ничего не вырезается.

**Лист стиля владельца.** Четвёртый файл пришёл вместе с макетом: палитра с хексами, типографика, карточки, иконки, отступы, страница «DO / NIE». Он тоже референс, и в двух местах расходится с этим документом. Расхождения решены в пользу ROSE.md, вот почему:

| Лист стиля | ROSE.md | Почему ROSE |
|---|---|---|
| Montserrat (заголовки и текст), Allura (рукопись) | Rubik 800 italic, Nunito, Caveat | У Allura нет кириллицы. Сайт на трёх языках, `/ru/` и `/uk/` упали бы в системный шрифт — ровно та поломка, которую ядро v25 уже чинило заменой Public Sans на Manrope. Caveat покрывает и латиницу с диакритикой, и кириллицу, B.4 |
| 70% фона — `#FFFDFC` молочно-белый | фон страницы `brand.100`, белого фона секций нет вовсе | Владелец прямым текстом не хочет белого фона. Белый в ROSE остаётся у карточек, B.8 |

Хексы листа стиля (`#A92F50`, `#D94B6A`, `#F7DDE3`, `#FDF5F6`, `#27252A`) — тот же малиновый ряд, что в B.2, но без проверки контраста. Палитра B.2 это он же, подогнанный под AA: числа в B.3 посчитаны, а не взяты на глаз.

Логотип растровый. Первым делом попросить у владельца **исходник** (SVG, AI, PDF или PNG от 2000px на прозрачном фоне). Нет исходника — знак перерисовывается в SVG по промпту K1.

## A.2 Что берём из макета

Визуальный язык целиком:

- светлый розово-кремовый фон вместо белого;
- крупные малиновые мазки кисти по краям экрана;
- рукописные подписи-заметки рядом с блоками: *Z nami zdasz*, *O nas ♡*, *Wybierz swój kurs!*;

- плитки курсов, одна активная сплошным малиновым;

- розовая полоса с цифрами;
- белые карточки отзывов на розовом фоне;
- сердечки, изогнутые стрелки, штрихи-«искры».

# ЧАСТЬ B — ДИЗАЙН-КОНТРАКТ v29

## B.1 Направление

Тёплый, дружелюбный, рукописный — но собранный. Фон — не белый, а розово-кремовый; малиновый — главный цвет, его много; рукописные заметки и сердечки — приправа, а не основное блюдо.

Школа по-прежнему должна выглядеть местом, где учат ездить. Проверка: закрыть глаза на орнамент — остаётся ли чистый, понятный сайт с ценой, статистикой и кнопкой? Если без орнамента он разваливается, орнамент несёт на себе то, что должна нести вёрстка.

## B.2 Палитра

Цвета сняты пипеткой с логотипа и макета и подогнаны под контраст.

```js
// tailwind.config.js
brand: {
  50:  "#FFFBFA",   // бумага — карточки
  100: "#FBEDEF",   // румянец — основной фон страницы
  200: "#F2B8C6",   // розовый — мазки, плитки, рамки иконок
  300: "#E98AA3",   // светлый малиновый — декоративные штрихи
  500: "#D4385E",   // МАЛИНОВЫЙ — кнопки, крупные заголовки, активная плитка
  600: "#C42D55",   // ссылки и мелкий красный текст, hover кнопки
  700: "#A14052",   // малина логотипа — тексты-акценты
  900: "#7E2B45",   // вино — тёмная полоса вместо чёрной
},
ink:   { DEFAULT: "#221B1E", 500: "#5E4A52", 300: "#9C8A91" },
line:  { DEFAULT: "#EBD3D9" },
state: { ok: "#1E7A56", err: "#8E1B12" },
```

Синего, жёлтого и серого `paper` из `REDESIGN.md` части B больше нет. Единственное исключение — синяя табличка `L` в фото, это часть реального мира.

Тёмная тема — перестановка, не инверсия:

```js
brand.100 → #1A1417   фон
brand.50  → #251C20   карточки
ink       → #F6E9EC   текст
ink.500   → #C9B3BB
brand.600 → #FF8FAB   красный текст и ссылки
brand.500 и brand.900 — без изменений, это заливки
мазки кисти — opacity .35
```

Правило из прошлых версий в силе: ни один цвет не определён только внутри `@media` или `[data-theme]`.

## B.4 Шрифты

Сайт на трёх языках — PL, RU, UK. Любой шрифт обязан покрывать `ąćęłńóśźż ĄĆĘŁŃÓŚŹŻ` **и** кириллицу, включая `ґєії`. Покрытие проверяется скриптом через fontTools, а не на глаз.

| Роль | Шрифт | Где |
|---|---|---|
| Дисплей | **Rubik** 800 italic | `h1`, `h2`, `PRAWO JAZDY`, цифры — тяжёлый наклонный, как слово в логотипе |
| Рукопись | **Caveat** 600/700 | заметки на полях, eyebrow, подписи к фото, слоган |
| Текст | **Nunito** 400/600/700 | абзацы, кнопки, поля, меню — мягкий, округлый, как в макете |
| Цифры | Nunito 800, `tabular-nums` | цены, телефоны |

Кисть для `PRAWO JAZDY` — по желанию: если в Google Fonts найдётся кистевой шрифт с latin-ext **и** кириллицей, прошедший проверку, — только для героя. Не нашёлся — Rubik 800 italic, и это нормально. Для RU/UK заголовков кисть без кириллицы не используется никогда.

Шкала:

```
display  clamp(3rem, 8vw, 6rem)      / .95 / -0.02em / Rubik 800 italic / uppercase
h1       clamp(2.25rem, 5vw, 3.75rem)/ 1.0 / -0.01em / Rubik 800 italic / uppercase
h2       clamp(1.75rem, 3.2vw, 2.5rem)/1.05/ 0       / Rubik 800 italic / uppercase
h3       1.25rem / 1.25              / Nunito 800
script   clamp(1.5rem, 3vw, 2.25rem) / 1.1 / Caveat 700, поворот -4°
body     1rem / 1.65                 / Nunito 400
label    0.8125rem / 0.06em          / Nunito 800 / uppercase
```

Весь самохост в `static/fonts/`, woff2, `font-display: swap`, `unicode-range` разбит на latin, latin-ext, cyrillic, cyrillic-ext.

```
Радиусы:  card 20px · tile 18px · button 999px (пилюля, как в макете) · input 14px
          polaroid 4px · avatar 999px
Тени:     card  0 1px 2px rgba(126,43,69,.06), 0 14px 30px -18px rgba(126,43,69,.28)
          hover 0 2px 4px rgba(126,43,69,.08), 0 22px 40px -20px rgba(126,43,69,.36)
          тень тёплая, с оттенком вина, не серая
Контейнер: 1280px, отступы 16 / 24 / 40
Секция:    py 64 / 96 / 128
```

**Кнопки:**

| Вариант | Вид |
|---|---|
| `primary` | пилюля `brand.500`, белый текст 600, стрелка `→` справа; hover `brand.600` и стрелка на 4px вправо |
| `outline` | пилюля, рамка `brand.500` 1.5px, текст `brand.600`, фон `brand.50`; hover — заливка `brand.100` |
| `ghost` | текст `brand.600` + рукописное подчёркивание-каракуля снизу, стрелка |

**Плитка курса:** `brand.50`, рамка `line`, радиус 18px, большая буква или короткое имя курса Rubik 800 italic, иконка, стрелка. Активная — `brand.500`, текст белый.

**Иконка-фича:** линейная иконка `brand.500` в круге 72px, круг — неровный розовый обвод «от руки» (SVG), а не `border`.

## B.6 Орнамент

Орнамент — набор статичных SVG, сгенерированных один раз скриптом и закоммиченных. Никаких SVG-фильтров `feTurbulence` в рантайме: они тормозят скролл на телефонах.

| Файл | Что | Цвет |
|---|---|---|
| `brush-1.svg` … `brush-4.svg` | мазок кисти с рваными краями и сухими прожилками, 4 формы: длинный, угловой, полоса, завиток | `brand.200` / `brand.500` |
| `heart-1.svg` … `heart-3.svg` | сердечко одним штрихом, чуть кривое, закруглённые концы | `brand.500` |
| `scribble-underline.svg` | подчёркивание-каракуля под словом | `brand.500` |
| `arrow-curly.svg` | изогнутая стрелка от руки | `brand.600` |
| `sparks.svg` | три-пять расходящихся штрихов, как у машины в макете | `brand.500` |
| `circle-hand.svg` | неровный круг-обвод для иконок | `brand.200` |
| `blob.svg` | мягкое пятно | `brand.100` чуть темнее фона |

Цвет всех штриховых элементов — `currentColor`, чтобы красить классом, а не пересобирать файл.

## B.7 Норма орнамента

Владелец хочет много — и его будет много. Но у «много» есть предел, после которого сайт автошколы становится открыткой.

1. **Мазки кисти:** только по краям секций и за фотографиями. Под текстом абзаца — никогда.
2. **Сердечки:** не больше **трёх в кадре**. Сердечко — точка в конце фразы, а не узор.
3. **Рукописные заметки** (Caveat): одна на секцию. Это голос школы, он не кричит в каждой строке.
4. **Стрелки:** только там, где заметка на что-то указывает.
5. Весь орнамент `aria-hidden="true"`, `pointer-events: none`, без текста внутри.
6. Орнамент не участвует в контрасте: текст всегда лежит на ровной заливке `brand.100`, `brand.50` или `brand.900`.
7. На телефоне орнамента вдвое меньше: мазки у краёв остаются, сердечки и стрелки в основном уходят.

Отдельная мысль про аудиторию: половина кандидатов на кат. B — парни 17–19 лет, и платят за курс часто родители. Розовый с малиновым им не мешает, а вот сердечки в каждом блоке — уже мешают. Поэтому сердечки дозированы, а малиновый — главный.

## B.8 Фон страницы — не белый

Секции чередуются так:

```
brand.100 (румянец)  →  brand.50 (бумага) с мазками по краю  →  brand.100
→  полоса-мазок brand.200 с цифрами  →  brand.100  →  brand.900 (вино, одна на страницу)
```

Чистого `#FFFFFF` фоном секции нет вообще. Белые — только карточки.
