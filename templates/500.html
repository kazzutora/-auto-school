Standalone on purpose. django renders this through server_error, which calls template.render() with no context and no request: the context processors never run, so site_settings is absent and any tag that reaches for the request has nothing to read. Extending base.html would put the header, the footer and the seo tags on a page that cannot supply what they need, and a 500 page that raises while rendering is the one failure with nowhere left to fall back to. So this file names its own html, pulls in the stylesheet and nothing else, and asks for site_settings behind an {% if %} — present if a future custom handler supplies it, harmlessly empty otherwise. The route to a human never depends on it: /kontakt/ is a plain link and needs no database to resolve. {% endcomment %} {% translate "Błąd serwera" %} — OSK Ostrycharz
