Not c-icon with a bigger size: an icon is a 24px pictogram from static/icons/sprite.svg, this is a 720x240 side elevation from static/illustrations/vehicles/. Two viewBoxes, two jobs. One file per vehicle, not one sprite: a page draws a single drawing, and a sprite would have it fetch the other seven with it — 29KB where 5 will do, on a page whose first screen budget has no room to spare. 3/1 is the drawing's own field, so the panel never letterboxes it and never crops it. The border makes it a sheet rather than a picture floating on the page — it is a technical drawing and it should read as one. label is required and becomes the accessible name: the drawing carries meaning a caption does not repeat, so it is an img to a screen reader rather than decoration to be skipped. {% endcomment %}
