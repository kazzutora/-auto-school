{% load static %} {% comment %} Icon, FRONTEND.md A.7. Not in the tech.md section 7 table: A.7 mandates a local sprite, and every component that shows an icon would otherwise repeat the same five lines of svg and the same static path. One holder for it. The sprite is a separate file, so use clones the symbol into a shadow tree here. The stroke rides along in presentation attributes on the symbol; the colour does not, which is the point — currentColor makes the icon take the colour of the text beside it. Sizes are spelled out rather than built from the prop: tailwind scans templates for whole class names, and an h- glued together at render time is a class it never sees and therefore never generates. Decorative by default. A.7 lets an icon stand alone only for the burger and the close button, and both of those pass a label instead. {% endcomment %}
