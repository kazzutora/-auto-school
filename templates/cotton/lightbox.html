The overlay is a native for the same reasons c-modal is one: the focus lock, Esc and the focus restore are the browser's job and it does them right. Alpine carries the one thing has no opinion about, which image is showing, and calls showModal() and close() on it. Arrow keys move between images while the dialog is open. They are bound on the dialog rather than the window so they do nothing when it is shut. Thumbnails are buttons, not links: there is no page to go to. Each one names the photo it opens so the list is usable without seeing it. {% endcomment %}
