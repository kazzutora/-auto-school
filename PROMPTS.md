# PROMPTS.md — готовые промпты для сессий

Каждый блок ниже копируется в новую сессию Claude как есть. Один блок = одна сессия = один PR.

**Порядок жёсткий.** S0.1 → S0.11 подряд, без пропусков. Только после того, как чек-лист «скелет готов» зелёный целиком (промпт `CHECK-SKELETON`), запускаешь S1.1 и дальше.

**Перед каждой сессией** убедись, что в репозитории лежат `tech.md`, `DEV.md`, `CLAUDE.md`. В Claude Code они подтянутся сами через `CLAUDE.md`. В веб-чате прикладывай `tech.md` файлом к каждой сессии.
