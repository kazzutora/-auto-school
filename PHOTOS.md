## 2. Как затемнять

Затемнение — не «положить чёрный полупрозрачный слой сверху». Оно работает только там, где лежит текст, и не трогает остальное. Иначе фотография превращается в грязь.

### Герой: текст слева, фото справа

```css
.hero {
  background-image:
    linear-gradient(
      90deg,
      rgba(27,27,32,.94) 0%,
      rgba(27,27,32,.86) 32%,
      rgba(27,27,32,.35) 62%,
      rgba(27,27,32,0)   88%
    ),
    image-set(
      url("/static/img/hero-dusk.avif") type("image/avif"),
      url("/static/img/hero-dusk.webp") type("image/webp")
    );
  background-size: cover;
  background-position: 70% center;   /* сдвиг вправо: интересное не под текстом */
}
```

На мобильном текст ложится поверх всей картинки, поэтому градиент разворачивается вертикально:

```css
@media (max-width: 767px) {
  .hero {
    background-image:
      linear-gradient(
        180deg,
        rgba(27,27,32,.55) 0%,
        rgba(27,27,32,.88) 55%,
        rgba(27,27,32,.97) 100%
      ),
      image-set(url("/static/img/hero-dusk-mobile.avif") type("image/avif"));
    background-position: center;
  }
}
```

### Полоса с текстом по центру

```css
.band {
  background-image:
    linear-gradient(rgba(27,27,32,.82), rgba(27,27,32,.82)),
    image-set(url("/static/img/band-road.avif") type("image/avif"));
  background-size: cover;
  background-position: center;
}
```

### Карточка бенто: текст снизу

```css
.bento-card::after {
  content: "";
  position: absolute; inset: auto 0 0 0; height: 62%;
  background: linear-gradient(180deg, rgba(27,27,32,0) 0%, rgba(27,27,32,.90) 78%);
  border-radius: inherit;
}
```

## 3. Правило, которое проверяется, а не прикидывается

Белый текст `#FFFFFF` даёт контраст 4.5:1 на фоне не светлее **`#767676`**.

Значит: **под текстом не должно остаться ни одного пикселя светлее `#767676`.**

Как проверить за минуту:

1. Открыть блок в браузере, сделать скриншот.
2. Пипеткой снять пять точек по площади текста: четыре угла и центр.
3. Любая точка светлее `#767676` — усиливать градиент, а не уменьшать шрифт.

Крупный заголовок от 24px полужирного допускает 3:1, то есть фон до `#959595`. Но лид и подписи под ним живут по строгому порогу, поэтому проще держать один.

Отдельно: **жёлтый акцент на фотографии не ставится никогда.** Жёлтый на произвольном фоне даёт непредсказуемый контраст. Плашка под словом в заголовке кладётся только на уже затемнённую область.

## 4. Обработка

```
исходник 2400px
  ↓ обрезка под соотношение
  ↓ AVIF (q≈50) + WebP (q≈75) + JPEG-фоллбэк
  ↓ ширины 480 / 960 / 1440 / 1920
```

| Назначение | Соотношение | Потолок веса |
|---|---|---|
| герой десктоп | 16:9 | 180 КБ |
| герой мобильный | 4:5 | 120 КБ |
| полоса | 21:9 | 140 КБ |
| карточка бенто | 3:2 | 90 КБ |
| постер видео | 16:9 | 120 КБ |

Герой грузится `fetchpriority="high"` и `loading="eager"` — он и есть LCP. Всё остальное `loading="lazy"`.

## 5. Как скачать

```bash
cp photos.txt      scripts/photos.txt
cp fetch_photos.sh scripts/fetch_photos.sh
chmod +x scripts/fetch_photos.sh
./scripts/fetch_photos.sh
```

Скрипт положит файлы в `static/img/source/` и заполнит `CREDITS.txt`.

Ширина запрашивается 2400px — этого хватит на все размеры и на ретину, но не настолько много, чтобы обработка тормозила.

## 6. Чего делать нельзя

- **Подписывать человека со стока как инструктора или ученика школы.** Ни одна из этих фотографий не может стоять в карточке «Piotr, instruktor od 8 lat». Карточка инструктора без реального фото не рендерится вовсе.
- Ставить лицо крупным планом там, где рядом написано «наши ученики».
- Брать снимки из Google Images и с чужих сайтов автошкол.
- Класть текст на незатемнённую фотографию «потому что и так читается на моём мониторе».
- Использовать один и тот же снимок в двух секциях подряд.

В демо для владельца все стоковые снимки помечаются водяным знаком `ZDJĘCIE POGLĄDOWE`, и об этом пишется прямо в письме. Реальные фото школы заменяют их при первой же возможности: даже посредственный настоящий снимок работает лучше идеального стокового.
